# 🎬 Movie Recommendation System

A Python-based application that uses the TMDB API to search for movies, display movie details, recommend similar movies, and perform basic sentiment analysis on reviews using TextBlob.

## Features
- Search movies
- View movie details
- Get similar movie recommendations
- Analyze review sentiment

## Technologies
- Python
- TMDB API
- Requests
- TextBlob

## Run
```bash
pip install requests textblob
python movie_recomendation_system.py
```
