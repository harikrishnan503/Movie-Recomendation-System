🎬 MOVIE RECOMMENDATION SYSTEM

Author: Hari Krishnan

Introduction:

This project is a Python-based Movie Recommendation System that uses the TMDB API to search for movies, display detailed movie information, recommend similar movies, and perform basic sentiment analysis on movie reviews using TextBlob.

Aim:

To develop an AI-based movie recommendation system that helps users discover similar movies and analyze audience sentiment through review analysis.

Technologies Used:

Python, TMDB API, Requests, TextBlob, and JSON.

Project Workflow:

Step 1: Enter a movie name.
Step 2: Fetch movie details from the TMDB API.
Step 3: Display movie information such as title, genre, rating, release date, and overview.
Step 4: Recommend similar movies based on the selected movie.
Step 5: Perform sentiment analysis on sample movie reviews using TextBlob.

How to Run the Project:

Install the required libraries using pip install requests textblob, add your TMDB API key, and run the Python script movie_recomendation_system.py. Enter a movie name when prompted.

Applications:

Movie recommendation systems, entertainment platforms, AI-based content discovery, sentiment analysis learning, and educational mini-projects.

Conclusion:

This project demonstrates the integration of API-based data retrieval and Natural Language Processing (NLP) to build an intelligent movie recommendation system with sentiment analysis capabilities.
